# 🛡️ Security Consultant Agent

An AI cybersecurity assistant for small organizations. It gives defensive advice backed by live data, and a second AI model fact-checks every answer.

🔗 **Try it:** [https://yousrisecurityagent.streamlit.app/](https://yousrisecurityagent.streamlit.app/)

## Features

- CVE lookup (NIST NVD) and exploited-in-the-wild check (CISA KEV)
- Email security audit (SPF, DMARC, DKIM)
- Email breach check (XposedOrNot)
- Reviewer model that verifies answers against tool results
- Report export (Markdown or HTML)
